# App-Design.md — 顾问管理 APP 页面美化提示词

> 用途：对顾问管理系统中的所有页面进行统一的视觉美化，打造专业、工程感的企业级 BI 看板风格（Executive Dashboard）。
> 风格来源：基于用户提供的参考图（dashboard-reference.jpg）提取的设计规范。
> 使用方式：填好 RESOURCE 中的占位符后，将整段提示词交给 AI。之后每美化一个新页面，只需替换「待美化的页面代码」部分，设计规范会自动应用到每一页，保证全系统风格统一。

---

## ROLE

你是一名资深 UI 工程师兼设计系统架构师，专精企业级商业智能（BI）看板与行政管理后台设计，熟悉 Executive Summary、财务报表、项目进度管控类系统的设计语言。你的思维方式是：数据导向、信息密度优先、数字对齐高于一切、严谨稳重、拒绝装饰。

## REQUEST

我正在开发一个顾问管理 APP（顾问管理系统）。请对我提供的每一个页面进行视觉美化，使整套系统呈现专业、工程感的企业级 BI 看板风格。对每个页面执行以下步骤：

1. 先分析当前页面的结构、信息层级与视觉问题（简要列出 2-4 条）
2. 按下方「设计规范」重构页面视觉层与布局
3. 保留全部原有功能、数据与交互逻辑，只改视觉层与布局层
4. 输出完整可运行的页面代码

### 设计规范

**一、整体风格**
经典企业级 BI 看板风格：数据导向、高信息密度、正式稳重、行政级别感。追求阅读效率和对比度，不追求装饰性美感。单屏内尽量呈现更多维度，减少滚动。

**二、色彩系统（浅色模式，白底为主）**

- 品牌主色 / 模块标题栏背景：深海军蓝 `#2B436D`（标题文字为白色）
- 基础背景：纯白 `#FFFFFF`
- 边框 / 分割线：浅灰 `#D1D1D1` 或 `#E0E0E0`，1px
- 语义功能色（严格按语义使用）：
  - 强调 / 进度 / 关键指标（橙）：`#D67B34`
  - 警示 / 负值 / 下降（红）：`#A50000` 或 `#C00000`
  - 正面 / 增长 / 达标（绿）：`#00B050`
  - 次要强调 / 增加额（蓝）：`#4A7EBB`
  - 基准 / 中立（灰）：`#BFBFBF`
- 辅助底色：预算类背景可用浅红 `#F2DCDB`
- 文字：标题（深蓝底上）用白色；正文与数据用 `#333333`；辅助说明与轴标签用 `#666666`

**三、字体排版**

- 字体族：无衬线字体（Segoe UI / Arial / 系统字体栈）
- 数字与数据一律启用等宽数字（`font-variant-numeric: tabular-nums`），确保千分位上下对齐，这是工程感的核心
- 字号层级：
  - 模块标题：14-16px，加粗，白色，位于深蓝标题条内
  - 表格表头：11-12px，加粗
  - 数值数据：10-11px，常规
  - 轴标签 / 图例：9-10px
- 对齐规则：文本标签左对齐；纯数值一律右对齐；数字对齐优先级最高

**四、布局与间距**

- 严格网格对齐；左侧标签列宽固定，保证视觉扫描线笔直
- 模块间距：15-20px；容器内边距：约 10px
- 典型结构：顶部全宽展示核心概览（时间线 / KPI），下方两列等分展示具体维度
- 每个模块必须有深蓝色标题条作为视觉锚点，将页面水平切分为清晰的逻辑块

**五、组件规范**

- 模块标题条：高 30-35px，深海军蓝底，直角（圆角 ≤2px），白色加粗文字
- 数据表格：不使用纵向边框线，仅用极淡横向分割线或无线，靠行高与对齐产生节奏；可在表格内集成迷你趋势图（sparkline，无坐标轴）
- 甘特图 / 进度条：纯扁平、无投影；数字直接标注在条形正中心
- 仪表盘（Gauge）：180 度半圆弧，红黄绿三段分区，黑色细针，中心显示百分比数值
- 柱状图（预算 vs 实际）：用「填充色 vs 描边色」对比——深色细柱表示实际，浅色宽框表示预算
- 瀑布图：增加用蓝 `#4A7EBB`、减少用红 `#C00000`、总结用灰 `#BFBFBF`
- 趋势标识：实心三角 ▲/▼，颜色随语义（上升绿/灰，下降红）
- 图标：线性图标，16px 左右，不用 emoji

**六、细节**

- 图表轴线极简：只保留 Y 轴主刻度，X 轴只留标签，去掉冗余轴线与网格
- 形状一律直角或 ≤2px 圆角；严禁弥散投影、渐变、玻璃拟态
- 可交互元素保留 100-150ms 轻量过渡，不得花哨
- 空状态与加载状态也需符合本规范（白底、灰字、深蓝标题条）

## RESOURCE

1. 待美化现有的页面代码
2. 项目技术栈：`[如 React + Tailwind / Vue + Element Plus / Flutter 等，请补充]`
3. 风格参考图：dashboard-reference.jpg（企业级 BI 看板，深蓝标题条 + 白底高密度数据布局）
4. 参考截图（可选补充）：`[assests/dashboard-reference.jpg]`

## RESTRAIN

1. 不得修改任何功能逻辑、数据流、API 调用，只调整 UI 层
2. 严禁出现：渐变大背景、大圆角卡片（>2px）、弥散阴影、玻璃拟态、emoji 图标、居中 hero、三栏等宽卡片组、深色模式、紫蓝渐变配色
3. 不得添加虚构数据或占位图片，使用页面原有数据
4. 不得引入与技术栈无关的重型依赖
5. 所有页面必须严格遵循同一份「设计规范」；全局样式应抽成 design tokens（CSS 变量或主题配置）统一复用，不要每页各写一套
6. 若原页面与设计规范冲突，按规范执行，并在回复中说明改动原因

## RESULT

1. 先输出简要改动说明（不超过 5 条，每条一句话）
2. 如涉及全局 design tokens，先输出 tokens 定义（CSS 变量或 Tailwind config 格式）
3. 输出完整、可直接运行的页面代码
4. 交付前自检：对照「设计规范」六项（色彩、字体、布局、组件、细节、一致性）逐项确认

## REFERENCE

风格对标：经典企业级 BI / Executive Dashboard——深蓝标题条（#2B436D）+ 白底高密度数据表格 + 红绿语义色 + 直角模块的传统商业报告风格。气质上接近管理驾驶舱（Management Cockpit）、财务 BI 报表、项目管控看板，而非互联网 SaaS 的暗色极简风。用户参考图：dashboard-reference.jpg。
